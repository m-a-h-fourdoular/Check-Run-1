## 🧠 فكرة اللعبة

في هذه اللعبة، تتحكم بمربع صغير 🔲

كلما تقدمت، سيزداد عدد الأعداء، ويزداد التحدي! ⚡

هل تستطيع:

* التركيز على أكثر من عدو في نفس الوقت؟ 👀
* اتخاذ قرارات سريعة؟ 🧩
* النجاة حتى النهاية؟
